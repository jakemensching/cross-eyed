# Crosseyed

One-of-a-kind hats handmade in Michigan from recycled rugs and carpets. Eyes on the cross.

Single-page site for Ashtyn Simerson's hat brand. Everything lives in `index.html` (inline CSS, JS, and SVG art, Google Fonts only).

## Still to swap in
Search `index.html` for these comments:
- `LOGO` for the real logo
- `HAT PHOTOS` and `PRICES` for real hat photos and prices
- `ABOUT TEXT` for Ashtyn's own about copy (photo is in: `ashtyn.jpg`)
- Verses currently use the KJV (public domain). Switching to the NIV needs Biblica's copyright notice.

## Run it
Open `index.html` in a browser. To host free, turn on GitHub Pages: Settings > Pages > Deploy from branch > `main` / root.
